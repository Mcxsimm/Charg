# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Linear (light), dark theme optional
- **Notes:** ChargéPro is a web tool for BTP project managers (chargés d'affaires): quotes, job sites, invoicing. Validated redesign: "Linear clair" — calm light surfaces, 1px borders, compact density, cards without shadow. All design values live in `tokens.css` (single source of truth): never hard-code a colour, font size, line height, spacing or radius.
- **Colour:** Accent indigo `--accent` #5B63D3 (fills: primary button, selection, bars) and `--accent-strong` for accent text/links. Neutrals `--bg` / `--surface` / `--sunken` / `--border` / `--text` / `--muted` / `--hover`. Status pairs `--red`, `--amber`, `--green`, `--blue`, `--violet` with their `-bg`. Orange (`--logo`) is reserved for the logo. Dark theme via `[data-theme="dark"]`, defaulting to `prefers-color-scheme`; choice stored in the `chargepro.theme` localStorage key.
- **Type & spacing:** Inter 400/500/600; six sizes only (12/16, 13/18, 14/20, 15/22, 24/32, 26/32 as `--text-*` + `--lh-*`); spacing on a 4px base (`--sp-*`); radii 6, 8, 12, pill (`--r-*`). Amounts use `tabular-nums`, right-aligned.

## Banned anti-aesthetics

- Glassmorphism / `backdrop-filter` **without** a high-contrast boundary. Exception, light glass is allowed only when all of these hold: at most one glass surface per screen, a 1px `--border-strong` border, and text on it that still meets the AA contrast target.
- Floating pastel pill badges for ordinary metadata
- Arbitrary decorative gradients and neon glowing borders
- Multi-color radial rainbow gradients on standard CTAs
- Cartoon empty-state illustrations (people waving / high-fiving)
- Nested scrollbars and icon bloat inside inputs

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** ≥ 4.5:1 for normal text; ≥ 3:1 for large text, UI component borders, and chart marks. Check both light and dark themes.
- **Touch / focus:** Minimum 44×44px touch targets (especially `mobile.html`); visible refined focus ring using `--focus` on every interactive element.

## Brand tone and microcopy voice

- **Voice:** Utilitarian & Minimal
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** UI language is French. Direct and professional: cold, precise, invisible. Every button starts with a verb ("Exporter le DPGF", "Enregistrer le devis"), and no "OK", "Valider", or "Soumettre" on their own. Errors state what happened and how to recover, without blaming the user. No exclamation marks or filler.

## Icon library

- **Library:** Project SVG set (stroke icons, Feather/Lucide style). Keep it; do not install another library.
- **Package / path:** `ICONS` map and `icon(name, cls)` helper in `index.html` (~54 icons, 24×24 viewBox, `fill="none"`, `stroke="currentColor"`, stroke width 1.9, round caps and joins, `aria-hidden="true"`).
- **Notes:** Always render through `icon()`. For a missing icon, add a path to `ICONS` drawn in the same stroke style (Lucide paths on the 24 grid fit). Size 16–20px. Gradually replace ad-hoc glyphs (☐ ☒ ✕) with `ICONS` entries. Icon-only buttons need an `aria-label`. No emoji as UI icons; do not mix in other sets.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the project SVG set (`ICONS` / `icon()` in `index.html`). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
